# Runtime dependencies for the Streamlit app.
#
# This file is what Streamlit Community Cloud picks by default, so it must stay
# small enough to install on a free CPU container. Two things matter here:
#
#   1. The CPU-only PyTorch index. Without it pip pulls the default PyPI wheel,
#      which bundles roughly 2.5 GB of CUDA libraries and blows the free
#      container's disk quota, failing the build with an opaque error.
#
#   2. Training-only packages (datasets, accelerate, evaluate, seaborn, tqdm)
#      are deliberately absent. The app never imports them and they slow the
#      install down. Use requirements_train.txt for local training and for the
#      Colab notebooks.
#
# CPU-only PyTorch wheel:
--extra-index-url https://download.pytorch.org/whl/cpu
